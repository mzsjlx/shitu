**标题：咨询门店 POI 坐标在自建旅游网站中的展示与使用许可**

您好，我们正在筹备一个美食旅游网站“食途”，计划先在重庆试点，之后逐步覆盖其他城市。网站会整理经作者允许使用的探店视频，展示对应门店，并计划提供门店之间的路线参考。未来考虑通过 Google AdSense 广告盈利，目前尚未正式上线。

我们的地图界面使用自己设计的 3D 样式和独立底图（现阶段使用 MapLibre 和 OpenStreetMap 数据），希望询问贵方是否有适合的 **门店 POI 查询及坐标使用** 方案。请结合这一场景说明：

1. 能否通过官方接口查询门店名称、具体分店、地址、地点坐标，以及是否有区分店铺位置和出入口的数据？
2. 查询结果能否显示在我们自建的非高德底图上，并与视频卡片关联？支持带广告的商业网站吗？
3. 若可以使用，允许存储哪些字段、保存多久、是否允许缓存、需要多久更新，门店关闭或迁址后有哪些处理要求？是否允许制作或保存坐标转换结果？
4. 返回的坐标系及建议的坐标适配方式是什么？如果将来叠加步行路线，路线结果可否用于同一自建底图，需要什么附加服务或授权？
5. 有哪些注册、认证主体、商业许可、署名和展示要求？重庆试点及未来城市扩张分别如何收费，调用、并发和数据规模如何计算？
6. 如果常规 API 不适用于上述需求，是否可以提供单独的数据授权或其他可行方案？请提供可供确认的书面授权范围及收费资料。

为评估数据覆盖情况，我们希望先核对下列原视频中有具体地址线索的门店（地址和实际营业状态仍需核实）：

- set coffee：重庆，环湖路 14 号附 14 号。
- 大堰酸菜米线：重庆，大堰一村 110 号附 3 号。
- 三样子：重庆，罗汉寺妙街 L1-6。
- 黔江鸡杂：重庆，大坪正街 87 号。

感谢，期待您告知适用的服务产品、授权范围和试点方式。
