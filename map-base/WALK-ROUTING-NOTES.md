# 道路节点试算与后续路由

2026-10-23。本轮完成本地研究样板，没有完成对外可执行的到店导航。底图显示、道路图计算、门店核实和入口连接分别管理；图上有线不提高门店核实状态。

## 当前样板

固定起点：OSM node/4592547287，朝千路，[106.5794059,29.56623]。固定终点：node/13912494389，解放东路，[106.5801262,29.5584767]。两者是原始道路节点，不是店门、吸附点或用户定位。

局部图中得到50段、51个原始点、11条源way，二维长度约1.07公里。长度是相邻原坐标的Haversine累加，不含坡度、上楼、排队、门口连接或真实步行时间。样板没有经过源标签中的台阶，但缺少台阶标签不构成无障碍保证。10条普通道路缺显式步行许可，过街条件与现场通行仍待核。

两家候选POI不在道路图里，仍为 source-record / entranceStatus=unverified / routeEligible=false。最近路段的几何距离不能当作可进入的门口连接；当前没有画穿楼、跨高差或连接未知过街点的补线。

## 数据与算法

- 数据来自已有2026-10-19 OSM局部缓存。源XML SHA-256：da9e7631a085ccc0782f84b9466c5aade68492505dff55dcb10f3672c917df10。没有为了本样板重新下载地图或依赖高德POI/路由。
- prepare-walk-network.mjs 保留752条highway way、3,812个被引用原节点的坐标和标签，生成 walk-network.json。它独立于用于显示的Protomaps瓦片，也独立于街道美术层。
- buildWalkGraph 以原节点ID建图，只连接源way中连续的已知节点；缺节点则断开，坐标相交或邻近不创建路口。Dijkstra在当前过滤图上按二维长度求路；局部缓存与规则不保证全城或现实最短。
- 当前保守地面研究模型排除桥隧、非零层、室内/面积、已知禁止/受限、有条件通行与未知权限值；节点门禁也单独判断。显式foot许可可覆盖泛用access限制，更具体的方向禁止不能被泛用许可覆盖。
- 机动车oneway不自动套到步行；尊重oneway:foot及foot:forward/backward。具体语义参考[OSM foot](https://wiki.openstreetmap.org/wiki/Key:foot)与[oneway:foot](https://wiki.openstreetmap.org/wiki/Key:oneway:foot)。缺失标签不等于经现场证明可通行，使用研究假设的普通道路在界面逐条标待核。
- “仅使用步行类资料”去掉缺少步行许可的普通道路。两个固定端点当前无路，界面清空线路与分段，保留道路点，不偷偷切回宽松条件或跨缺口连线。

普通页按需读取本地JSON，12秒超时可重试；视角新操作取消旧加载聚焦。单文件内嵌同一图。试算时隐藏候选卡及其圆点，只显示两个道路端点，关闭后恢复候选。没有把想去清单自动变成已核实路线。

## 验证与扩展条件

WALK-DATA-VERIFICATION.json为独立原XML与18项算法检查，WALK-UI-QA.json为22项浏览器检查，WALK-LOADING-QA.json为4项加载/单文件检查，WALK-FINAL-QA.json为2026-10-23最终4项回归。独立读取XML核对所有网络节点、way顺序与标签及样板每条相邻边；不是只重复实现本身。

扩展到任意门店或第二城市前，至少要补齐：分店与当前文字地址、可用且对应本店的素材、实际入口及楼层/高差、入口到公共步行道路的可信连接、过街与现场限制。规则不完整时应显示未覆盖/待核，不生成估计导航。

全国阶段须另选可维护的城市/区域路由数据和引擎，记录版本、覆盖范围、更新/回退、服务接口及许可；本地小图不能直接当全国导航引擎。生产接口还需处理多层连接、受限/有条件通行、关系限制、无障碍和边界外候选路径。当前不申请路由账号、不调用外部示例服务、不承诺实时性。
